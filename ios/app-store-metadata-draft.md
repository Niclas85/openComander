## English (en-US)

Subtitle: Dual-Pane File Manager

Promotional text:

Organize files in two panes with drag & drop, ZIP, trash, action history and undo.

Description:

OpenCommander is a free, open-source dual-pane file manager for iPhone and iPad. It helps you organize files locally without an account, ads, tracking or forced cloud sync.

Each pane has its own folder tree and file list. Select multiple files and folders, then drag them between panes to copy or move them.

Features:

- Two independent file panes
- Copy or move with drag & drop
- Multi-selection
- Rename, delete and local trash
- Undo with action history
- Create ZIP archives and browse them like folders
- Progress feedback for file operations
- Light and dark themes
- Interface in 20 languages: English, German, French, Spanish, Italian, Portuguese, Dutch, Simplified Chinese, Japanese, Korean, Arabic, Hindi, Russian, Turkish, Polish, Indonesian, Vietnamese, Thai, Ukrainian and Swedish
- No ads, tracking or user account

OpenCommander works in the app’s local Documents area, which is accessible through Apple’s Files app. The app does not upload files to provider servers and contains no analytics SDK.

File operations can modify, move or delete files. Keep separate backups of important files.

Keywords:

The first iOS release of OpenCommander, featuring dual panes, drag & drop, ZIP support, local trash, action history, and light and dark themes.

## App Review notes draft

OpenCommander has no login, account, purchases, ads, analytics or network-dependent feature. It works in its local Documents directory. To test with custom files, add them to OpenCommander through the Files app. The two file panes are independent. Select an item, choose Copy or Move, then long-press and drag it to the opposite pane or a folder. ZIP archives are read-only while browsing. Trash moves items to a hidden `.OpenCommanderTrash` folder beside the source so the action can be undone from the app history.
